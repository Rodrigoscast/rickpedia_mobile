# Rickpedia Mobile

Aplicativo Flutter que consome a API de Rick and Morty e utiliza autenticação anônima com Firebase.

## 🚀 Funcionalidades
- ✅ Autenticação anônima com Firebase
- ✅ Listagem de personagens via API Rick and Morty

## 🔧 Tecnologias
- Flutter
- Dart
- Firebase Auth
- HTTP

## ▶️ Como executar

```bash
git clone https://github.com/seuuser/rickpedia-mobile.git
cd rickpedia-mobile
flutter pub get
flutter run
```

## 🧪 Firebase - Configuração
1. Crie um projeto no Firebase Console.
2. Ative o login anônimo em **Authentication > Sign-in method**.
3. Adicione um app Android com o pacote `com.seuprojeto.rickpedia`.
4. Baixe o arquivo `google-services.json` e coloque em `android/app/`.
5. Execute o projeto.
